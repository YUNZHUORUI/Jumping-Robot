# RL-Based Control for Hybrid Hopper Dynamics: Ballistic Launch & Attitude Stabilization
This repository contains the simulation environment and reinforcement learning (PPO) control framework for a 2D Hopper robot. The project focuses on solving the Hybrid Dynamics control problem, specifically optimizing the energy-efficient "release" state for ballistic jumping and stabilizing landing attitude during the under-actuated flight phase.
