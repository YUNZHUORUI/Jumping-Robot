# Dated Quadhopper iterations

This directory contains historical single-file Quadhopper experiments named by
their iteration dates. They are retained for reference and are not imported by
the current modular implementation in `Hopper_simu/Quadhopper/`.

Run archived scripts from the repository root if an old experiment needs to be
reproduced. The maintained 2D implementation is under `Hopper_simu/Quadhopper/`.
