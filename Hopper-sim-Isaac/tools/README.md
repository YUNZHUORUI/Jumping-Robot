# Tools

Small one-off diagnostics and inspection helpers live here instead of the
project root.

- `diagnostics/diag_gpu_cartpole.py`: machine-level Isaac Lab GPU smoke test.
- `diagnostics/diag_quadhopper_env.py`: raw random two-hop environment smoke
  test.
- `diagnostics/diag_quadhopper_wrapper.py`: random two-hop environment plus
  frozen teacher/wrapper smoke test.
