# Quadhopper project context

For any work involving `Quadhopper_Isaac`, the jumping robot, new training tasks, trajectory optimization, waypoint tracking, obstacle traversal, or ring traversal, first read and follow `skills/quadhopper-baseline/SKILL.md` and the references it routes to.

Treat `Quadhopper_Isaac` as the preserved baseline. Prefer new task modules/packages over destructive edits to the baseline, and explicitly separate robot-physics changes from task changes.
